# INCIDENT INVESTIGATION REPORT: RCA-2025-00042
**Service:** Payroll Service  
**Completion Date:** 2025-10-15T11:00:00Z  
**Linked Incidents:** INC-2025-00119  
**Investigation Owner:** Core HR Systems Operations  

## Summary
The weekly scheduled payroll calculation batch failed to finish within the agreed SLA window, leading to HTTP 504 gateway timeouts across the employee self-service portal during morning peak usage.

## Timeline
- 06:00 UTC: Scheduled cron batch triggered.
- 06:24 UTC: Active database client connections crossed the 90% threshold.
- 06:28 UTC: First database connection acquisition timeout alarms fired on worker nodes.
- 07:10 UTC: Batch processing aborted manually by the operations team to restore portal accessibility.

## Root Cause
The batch processing worker pool dynamically scaled up to 64 concurrent threads, saturating the primary PostgreSQL maximum connection pool (max_connections=100) and stalling database connection acquisition for both batch jobs and API calls.

## Contributing Factors
Absence of connection pool limits between the asynchronous background workers and synchronous user-facing API threads.

## Corrective Actions
Configured the database batch worker thread cap to 32 and increased the lock acquisition timeout on the primary ledger schema.
