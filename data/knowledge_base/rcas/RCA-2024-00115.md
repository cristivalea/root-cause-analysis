# INCIDENT INVESTIGATION REPORT: RCA-2024-00115
**Service:** API Gateway  
**Completion Date:** 2024-04-15T02:00:00Z  
**Linked Incidents:** INC-2024-00244, INC-2024-00359  
**Investigation Owner:** Core Platform  
**Root Cause Category:** Capacity / Resource Exhaustion  
**Business Impact:** EUR 20,500 (estimated)  

## Summary
Gateway pods were evicted because their memory request was far below real usage at peak.

## Root Cause
The gateway pods requested 512Mi but used close to 2Gi at peak because of large TLS session caches. Under node memory pressure Kubernetes evicted them first.

## Five Whys
1. Why were connections dropped? Gateway pods were evicted.
2. Why were they evicted? Nodes ran low on memory and the pods used more than they requested.
3. Why was usage so high? TLS session caches grew with the number of clients.
4. Why was the request so low? Resource requests were never updated after launch.

## Contributing Factors
- **Capacity:** Memory request far below usage.
- **Configuration:** TLS session cache without a size limit.
- **Monitoring:** No alert on requested versus used memory.

## Corrective Actions
Set requests to real usage and capped the TLS session cache.

## Preventive Actions
Monthly review of requested versus used resources for platform workloads.
