# INCIDENT INVESTIGATION REPORT: RCA-2025-00114
**Service:** Payment API  
**Completion Date:** 2025-11-20T14:00:00Z  
**Linked Incidents:** INC-2025-00401  
**Investigation Owner:** Payments Platform Engineering  

## Summary
Intermittent HTTP 500 errors and elevated latencies exceeding 5 seconds were observed across credit card checkout flows following a maintenance window.

## Timeline
- 13:58 UTC: Release deployment completed on Payment API pods.
- 14:32 UTC: Automated monitors triggered alerts on HikariCP connection pool starvation.
- 15:17 UTC: Service mitigated by rolling restart of pods and increasing maximum pool size.

## Root Cause
Database connection pool exhaustion caused by unclosed SQL sessions inside the payment retry handler block during error response flows.

## Contributing Factors
Inadequate unit and integration test coverage for transient gateway errors.

## Corrective Actions
Implemented explicit try-with-resources blocks across all repository query methods and enabled HikariCP connection leak detection thresholds.
