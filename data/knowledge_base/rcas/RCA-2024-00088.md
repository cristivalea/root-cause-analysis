# INCIDENT INVESTIGATION REPORT: RCA-2024-00088
**Service:** API Gateway  
**Completion Date:** 2024-09-18T08:15:00Z  
**Linked Incidents:** INC-2024-00891  
**Investigation Owner:** Edge Platform Operations  

## Summary
A production API gateway outage caused intermittent TLS handshake failures for all mobile and web clients routing through the public edge layer after a certificate renewal was missed during a weekend automation window.

## Timeline
- 02:45 UTC: Automated certificate rotation job attempted renewal on edge proxy nodes.
- 03:10 UTC: Renewal hook exited with a non-zero status and logged a silent validation warning.
- 04:35 UTC: Public API clients began receiving handshake and certificate validation errors.
- 05:20 UTC: Platform team replaced the expired wildcard cert and restored service health.

## Root Cause
The wildcard TLS certificate on the public edge proxy cluster had expired because the automated cert-manager renewal hook failed silently and did not trigger a human escalation before the expiry threshold.

## Contributing Factors
Insufficient alerting on certificate expiry for non-critical automation tasks and weak validation around renewal job exit codes.

## Corrective Actions
Replaced the expired certificate, repaired the renewal hook, and added a production alert for any certificate renewal failure that persists beyond 24 hours.
