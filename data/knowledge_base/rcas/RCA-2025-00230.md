# INCIDENT INVESTIGATION REPORT: RCA-2025-00230
**Service:** Billing Service  
**Completion Date:** 2025-12-05T09:30:00Z  
**Linked Incidents:** INC-2025-00512  
**Investigation Owner:** Finance IT Operations  

## Summary
End-of-month invoice processing experienced severe query latency, causing downstream billing webhooks and customer PDF invoice generation to fail with timeout errors.

## Timeline
- 22:00 UTC: Automated end-of-month aggregation process initiated.
- 22:45 UTC: Database CPU utilization spiked to 100% and stayed saturated.
- 23:30 UTC: Billing batch paused; database administrator executed query execution plan analysis.
- 01:15 UTC: Missing index recreated manually; queue resumed and cleared by 02:30 UTC.

## Root Cause
The composite index `idx_invoices_period_status` on the billing database had been dropped during a routine index defragmentation script earlier in the week, forcing batch queries into full table scans against millions of historical invoice records.

## Contributing Factors
Index optimization scripts ran with insufficient post-maintenance index validation checks.

## Corrective Actions
Recreated the missing composite index, added an automated daily schema integrity check against production databases, and adjusted slow query alerts.
