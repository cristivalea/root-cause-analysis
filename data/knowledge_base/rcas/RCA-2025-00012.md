# INCIDENT INVESTIGATION REPORT: RCA-2025-00012
**Service:** User Profile Service  
**Completion Date:** 2025-06-14T10:15:00Z  
**Linked Incidents:** INC-2025-00615  
**Investigation Owner:** Consumer Identity Platform Team  

## Summary
User profile reads intermittently failed across the customer portal after a microservice update, causing inconsistent account page renders and missing profile attributes in downstream API responses.

## Timeline
- 09:40 UTC: Gateway microservice update completed and rolled out to production.
- 09:49 UTC: Error rate increased sharply on serialization requests.
- 10:02 UTC: Resident engineering team isolated the mismatch to a field tag collision in schema generation.
- 10:44 UTC: A backward-compatible rolling revert restored stable API behavior.

## Root Cause
A Protobuf contract mismatch occurred because the User Profile service and the upstream gateway used colliding field tag numbers in the same message definition, leading to serialization errors in live traffic.

## Contributing Factors
Schema compatibility checks were absent during the release and there was no contract validation gate before deployment.

## Corrective Actions
Reverted the incompatible contract update, added schema compatibility validation to the CI pipeline, and implemented a centralized contract registry for cross-service message versions.
