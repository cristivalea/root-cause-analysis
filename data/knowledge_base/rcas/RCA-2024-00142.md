# INCIDENT INVESTIGATION REPORT: RCA-2024-00142
**Service:** API Gateway  
**Completion Date:** 2024-05-09T10:00:00Z  
**Linked Incidents:** INC-2024-00375, INC-2024-00493  
**Investigation Owner:** Core Platform  
**Root Cause Category:** Configuration Error

## Summary
A WAF rule moved to blocking mode matched normal profile updates that contain apostrophes.

## Root Cause
Rule 942100 treats an apostrophe followed by a keyword as SQL injection. Names like O'Connor in profile updates matched it, and the rule was switched to blocking without reviewing the detection-mode hits.

## Five Whys
1. Why were requests blocked? WAF rule 942100 returned 403.
2. Why did it match? Normal names with apostrophes looked like SQL injection.
3. Why was it blocking? It was moved to blocking mode.
4. Why was the risk missed? Detection-mode hits were not reviewed before the switch.

## Contributing Factors
- **Change / Release:** Rule set switched to blocking.
- **Process:** No review of detection-mode results.
- **Monitoring:** 403 rate was not alerted per route.

## Corrective Actions
Added an exclusion for the profile name fields.

## Preventive Actions
WAF rules stay one week in detection mode and their hits are reviewed before blocking.
